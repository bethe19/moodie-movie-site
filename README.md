## Moodie

Discover and explore movies and TV shows based on your mood. Build your watchlist and find what to watch next.

### Tech Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- React Router, TanStack Query

### Getting Started

```sh
npm install
npm run dev
```

### Environment Variables

Create a `.env` file at the project root with:

```
VITE_TMDB_API_KEY=your_tmdb_api_key_here
```

Optionally, you can override at runtime by storing a value in `localStorage` under `tmdb_api_key`.

### Build

```sh
npm run build
npm run preview
```
